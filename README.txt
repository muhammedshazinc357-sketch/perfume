AURA Perfume Store — starter demo

Files:
- index.html: storefront structure
- styles.css: responsive styling and intro animation
- script.js: demo add-to-bag interactions

Run:
1. Extract the ZIP.
2. Open index.html in a modern browser.

The intro animation is CSS-driven: a water-inspired circular ring expands, then the perfume bottle rises and rotates into place. The storefront is a front-end demo; checkout, inventory, and payment are not connected. Replace sample products/prices and connect a backend/payment provider before launching.
